# v1.1.2 release notes

Unreleased. Patch release: a duplicated-message fix for phones whose clock runs ahead, and a deploy smoke check that works on private Unix sockets.

## Changes

- Retire a sent message's pending bubble against the server's clock. The prompt and image routes now return their receipt time (`at`), and the composer re-stamps the echo with it. Previously the echo carried the phone's time and the transcript the host's, so a phone running even a second ahead showed every mid-turn message twice until the agent went idle (#77).
- Make `bun run deploy` smoke the address the service actually serves. `package.json` passed `${BORDR_URL:-http://127.0.0.1:7682/}` to `scripts/smoke.ts`, and the script shell never reads `.env`, so the loopback default always overrode `BORDR_URL` and every `SOCKET_PATH` deploy failed with `ERR_CONNECTION_REFUSED` after a successful restart. The argument is gone; `scripts/smoke.ts` reads `BORDR_URL` itself (#78).
- With no `BORDR_URL`, `scripts/smoke.ts` falls back to the installed unit's `SOCKET_PATH` through a short-lived loopback forwarder. The forwarder admits only connections whose first request carries a random per-run token held in the smoke process's memory, so it never extends the socket's file-permission boundary to other local users.

## Upgrading

No configuration changes. Setting `BORDR_URL` to the HTTPS address printed by `tailscale serve` remains the recommended smoke target, since it also exercises the Tailscale proxy.
