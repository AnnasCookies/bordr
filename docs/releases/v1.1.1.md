# v1.1.1 release notes

Patch release for v1.1.0's private Unix-socket deployment, plus refreshed demo media.

## Changes

- Honour `X-Forwarded-Host` on private Unix sockets (`SOCKET_PATH`) so browser `POST` writes through `tailscale serve unix:…` match `Origin` instead of failing the CSRF check against `Host: localhost` with `403` (#74).
- Isolate named `bordr` instances (`--instance <name>`) with separate socket directories, `.env.<name>` files, state directories and published releases without restarting or touching `herdr-session.service` (#73).
- Close superseded SSE event streams, deduplicate concurrent resyncs, fence heartbeat fallback ownership, restore folder-derived workspace labels and preserve cached remote navigation (#72, fixes #70).
- Extend `scripts/smoke.ts` and `scripts/check-socket-boundary.py` to exercise same-origin and cross-origin `POST` requests across the Unix-socket boundary.
- Refresh `.github/media/` screenshots and `demo.gif` / `demo.mp4` against an isolated synthetic demo server showcasing worktree nesting, pull-request check badges and workflow sub-agents.
